# 🕹️ Java Swing 2D Pac-Man Game Engine

A classic interactive 2D Pac-Man game architecture built from scratch utilizing Java Swing and AWT graphics loops. This project leverages an open-source structural layout baseline which I am refactoring to evaluate object-oriented design patterns, collision mechanics, and input latency processing in Java desktop environments.

## ⚙️ Engineering Focus Areas
- **Graphics & Rendering:** Utilizing custom Swing paint components to render grid layouts and active game characters.
- **State Tracking:** Monitoring player scores, lives, active entity coordinates, and win/loss states dynamically.
- **Event Controls:** Binding player navigation seamlessly using Java KeyListener hooks.

## 🛠️ Tech Stack
- **Language:** Java (JDK)
- **UI & Graphics:** Java Swing & Java AWT Layout Managers
